# Demo Clinica

## Narrativa prevista

La demo final debe mostrar como RetinaCare podria incorporarse al trabajo diario de una clinica sin afirmar que existe diagnostico automatizado.

Recorrido objetivo para fases posteriores:

1. Entrar al sistema.
2. Ver dashboard de una clinica.
3. Registrar paciente ficticio.
4. Crear screening.
5. Cargar fotografias de ambos ojos.
6. Evaluar manualmente calidad.
7. Mostrar el espacio de IA futura.
8. Explicar que la IA esta desactivada hasta validacion clinica.
9. Registrar revision profesional.
10. Crear seguimiento o referencia.
11. Consultar historial.
12. Generar reporte.
13. Mostrar estadisticas operativas del centro.

## Mensaje obligatorio

Version beta - Este sistema no realiza diagnostico automatizado.

Prototipo para validacion de flujo de trabajo. No destinado a diagnostico medico.
